About {{ config.SITE_NAME }}

{{ config.SITE_NAME }} is the fictional encyclopedia of the AIWORLD universe. It is a purely local, offline website: everything it shows comes from the canonical world database on this computer.

How it works

  • The canonical source of truth is the SQLite database world.db.
  • Articles, facts, links and categories are generated live from that database on each page request.
  • Pages are plain server-rendered HTML and CSS — there is no JavaScript anywhere on this site.
  • The site is read-only. It never invents facts and never writes to the canon.

How the world grows

New entities, facts, relationships and events are created through the World Builder, which validates every change before it is stored. As soon as the World Builder records a new fact, it appears here automatically on the next page load.

What is not here

If a topic has no canonical record, {{ config.SITE_NAME }} shows nothing rather than guessing. Absence of an article means the world has no established information about it yet.
